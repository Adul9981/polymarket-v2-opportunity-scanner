## 2. 赔率形态统计

```text
单图（G1/G2）形态分布：
  B4 直线阴跌（弱侧归零）       8 次
  A1/A2/A5 反转（深水/中位翻盘） 5 次

整场（Moneyline）形态分布：
  A3 折价修复 / 热门压制         6 次
  A1/A2 反转（让一追二）         3 次
  B4 阴跌（下狗归零）            3 次
```

关键结论：

```text
1. "深水区多数归零"仍是基准（B4 出现 8/12 图），反转是少数；
2. 让一追二深反 3 次全部出现在 BO3（K27 6c、paiN 29.5c、FUT Map2 21.5c），
   BO1 无此类机会（BO1 是纯硬币波动）；
3. 热门压制 6 次，赛前档位决定回报：62c 有值（+61%）、77-93c 无值（<30%）。
```

## 3. 策略模式（可执行）

### S-CS1：BO3 让一追二深反（正期望样本）

```text
适用：BO3 系列赛 Moneyline / 单图 Map2
结构：强侧先赢 Map1（或领先），弱侧整场/单图被砸到深水
买入：
  - 深水区（整场 <=20c，或单图 <=15c）小仓彩票预算（归零可接受）
  - 反转确认后加仓：单图价格上穿 0.5 / 整场上穿 0.35（25-40c 段加仓）
止盈：
  - 上穿 0.7 后止盈 60-80%，剩余搏系列赛
样本：K27 6c->100c、paiN 29.5c->98c、MGLZ G2 25c->100c、FUT Map2 21.5c->100c
风险：深水无脑接 = 接刀（FUT Map1 37c 接刀归零反例）
```

### S-CS2：热门压制赛前早建仓（低回报但稳定）

```text
适用：资格赛/小组赛明显强弱分明的 BO3（赛前整场 55-65c 档）
买入：赛前 <55c 早建仓（回报 >80%），>75c 不追
样本：Acend 62c（+61%）有价值；OG 77.5c、Phantom 79.5c、NRG 93c 无价值
注意：单图开盘段（46-60c）是唯一低吸窗口，但要容忍中段回撤
```

### S-CS3：五五开场观察不参与（方向不定）

```text
适用：5:5 开盘的强强对话（EYE/PHA、BetBoom/FaZe）
规则：不主动下注；等 Map1 方向确认后再决定
若持有：高位（86c+）必锁盈（EYE 86.5c 未锁盈回撤 38c 反例）
```

### S-CS4：BO1 硬币波动只按彩票（无价格止损）

```text
适用：主赛事小组赛 BO1（Group B/C 单图）
规则：彩票预算（归零无感），不设价格止损（B8 40->8.5->70 卖飞反例）；
      或直接不参与
```

### S-CS5：弱侧反扑 = 锁盈/逃命窗口（不追高）

```text
规则：弱势侧反扑到 50c+（或整场 45c+）是减仓窗口，不是加仓点
样本：EYE 86.5c、Partizan 91c 高位未锁盈归零；paiN/NAVI 反扑后回落
```

## 4. 交易纪律对照（本系列真实交易）

```text
反面样本（全仓 + 接刀 + 无止损 = 归零公式）：
  FUT vs MOUZ Map1：37c 中位接刀全仓 350 归零
  （同日 MOUZ Map2 21.5c 反转 4.6 倍——位置与确认时机决定盈亏）

规则强化：
1. 接位必须等启动确认（上穿 0.3/0.5），阴跌途中接 = 接刀；
2. 深水反转按彩票仓，单笔 <=30%、归零可接受；
3. 高位（80c+）锁盈是规则不是选择；
4. "以为能反弹"不是理由——反弹需要信号，不需要希望。
```
