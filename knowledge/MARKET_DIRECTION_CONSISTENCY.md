# 预测市场方向一致性研究（到期前时间轴）

> 定位：预测市场层面的通用研究（对标局内四阶段框架的"方向一致性曲线"），
> 按板块（sports / crypto / politics / esports）分层，属最高优先级知识库研究项。

## 1. 核心概念

```text
方向一致性 D(t)：市场在"到期前 t"时刻的领先方向（价格>0.5 的一侧），
  与最终结算结果一致的比例。
  - 按绝对时间：到期前 30d / 15d / 7d / 48h / 24h / 12h / 6h / 2h
  - 按时间进度：市场生命周期进行到 30% / 50% / 70% / 90% 时
延续概率 C(T1→end)：在 T1 时刻方向一致的市场中，最终仍一致的占比
  = P(最终正确 | T1 时正确)。回答"预压注后跟随正确方向，坚持到最后的概率"。
板块分层：sports / crypto / politics / esports 等 tag 分别统计，
  输出各板块的 D(t) 曲线与 C 矩阵（板块间价格发现效率不同）。
```

## 2. 与局内四阶段框架的关系

```text
局内框架（LOL/CS/DOTA）：t=0/10/20/30 分钟的方向一致性（36%→57%→68%→79%→81%）
  是"单场价格发现效率"；本研究的 D(t) 是同一概念在市场到期时间轴上的推广：
  "市场多久以前就已经知道答案"。
策略用途：
1. 预压注：早期一致性高（如到期前 30d 就 >70% 的板块/题型）→ 提前押注价值高；
2. 跟随正确方向：C 矩阵高 → 早期方向正确时值得持有/加仓；
3. 避坑：早期一致性低（如体育爆冷型）→ 早期重仓风险高。
```

  - 统计到期前 48h/24h/12h/6h/2h 的 D(t) 与 C 矩阵，按板块分层；
  - 样本量：近期市场为主，先跑通方法。
阶段 2（积累后做）：中长期限一致性
  - 从现在开始按板块建采集队列（sports/crypto/politics/esports），
    记录"到期前 30 天起"的每日价格；
  - 30 天后开始产出 30d/15d/7d 口径的 D(t) 曲线（滚动窗口）；

## 5. 落地步骤

```text
1. 定义采集队列：按 tag（sports/crypto/politics/esports）+ closed/active 筛选。
2. 每日快照落盘（复用 fetch_price_snapshot / 每日抓取），含 endDate 与结算结果。
3. 结算后回填结果，计算 D(t)（多时间口径）与 C 矩阵。
4. 输出：板块 × 时间口径 的一致性热力图 + 延续概率矩阵（报告 + HTML 页面）。
5. 结论用于策略：预压注时机、持有时间价值、板块间定价效率排名。
```
