# 集体智慧层

Crowd Consensus Layer · 弹幕共识预测情报
**比分告诉你发生了什么，集体智慧告诉你将要发生什么。**

## 一、它是什么

- 一个叠加在比赛之上的**预测情报层**：用观众群体的实时判断，输出"谁会赢、这个 BP 行不行、这局有没有问题"的共识信号

- 本质是预测：把上万名观众的集体直觉，变成可检验、可校准的赛果倾向

- 弹幕只是原料，产品输出的是"共识"——不是转述谁说了什么

## 二、一条链路（三步）

1弹幕 · 原料直播间观众实时发言，上万双眼睛同时在看。原始媒介。
2共识 · 提炼聚合为集体判断：看好方向、BP 正负锚点、灰信号集中度。带样本量与置信。
3预测 · 输出赛果倾向 + 风险标注 + 可溯源时间窗；赛后回填兑现率，持续校准。

弹幕是什么（产品内说明）：直播间观众的实时评论。我们不做"转述弹幕"，而是把上万条发言聚合成"集体共识"——弹幕是原料，共识是产品。

## 三、产品里你会看到什么

| 模块 | 内容 |
| --- | --- |
| 共识指数 | 观众看好方向的占比与强度（谁被看好多、共识是否集中） |
| 关键锚点 | BP 后战绩情报：选手×英雄历史战绩/胜率（正锚点 / 负锚点），如"该英雄 7-0，观众判胜" |
| 灰信号风险 | 剧本/假赛/卡盘质疑的集中度——永远标注"观众质疑，非结论" |
| 溯源与置信 | 每条共识带：置信度 + 样本量 + 时间窗口 + 数据来源 |

## 四、为什么有价值

- **提前量**：BP 刚锁定、比赛刚开打，观众的判断就出来了——比数据网站和盘口重定价更早

- **大样本**：上万条实时发言聚合，方向稳定，噪音可被稀释

- **真实情绪**：数据网站给不了"观众此刻怎么看"——这是行为信号

- **灰信号维度**：剧本/假赛质疑是传统数据源完全缺失的一层，且可对照兑现率检验

- **验证闭环**：每条预测赛后回填，形成可统计的兑现率——"共识靠不靠谱"有数据说话

## 五、边界与纪律（清清爽爽）

只给事实与统计 · 每条可溯源 · 无样本不硬撑（显示"样本不足"）· 无信号不硬造（显示"今日无信号"）
灰信号（剧本/假赛质疑）只作风险标注，不作结论；不展示弹幕流与用户身份，只给聚合结论。

- 覆盖：LoL（LPL/LCK/LEC 等）、CS2、DOTA2 等主流电竞联赛

- 校准：所有"共识预测"赛后回填兑现/未兑现，持续更新统计页

- 诚实：弹幕反映的是"观赛人群的集体反应"，不是全部观众——大样本下方向稳定，但永远带置信与样本量
