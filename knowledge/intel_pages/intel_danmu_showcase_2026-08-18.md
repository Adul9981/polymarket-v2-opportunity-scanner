# 观众集体智慧 电竞弹幕情报库

从直播弹幕中提炼"集体的判断"，为预测市场决策提供信息差引擎
  2026-08-18 · 思路展示 + 首日实战成果

  01 · WHY

## 为什么做这件事

预测市场的胜负，本质是信息差的竞争。职业解说的直播间弹幕里，藏着最实时、最廉价、也最被低估的"集体智慧"——观众在看比赛时，会用嘴投票。

### 实时性

弹幕秒级反映比赛进程，先于多数公开数据；密度峰值 = 关键时刻。

### 集体性

单条弹幕不可信，但几百人的共识、分歧与情绪反转是有统计意义的信号。

### 信息差

观众常比盘面更早感知"这支队伍不对劲"——灰信号、卡盘质疑、版本洞察都在弹幕里。

  02 · HOW

## 完整链路

一条从"弹幕"到"情报"再到"交易辅助"的流水线，全部自动化、可回溯。

    1**抓取**虎牙 / SOOP 实时 WebSocket，轻量无浏览器
    →
    2**监控**多直播间并发，自动重连，持续落盘
    →
    3**分析**队伍 / 选手 / BP / 盘口 / 局势 / 灰信号
    →
    4**画像**队伍画像 + 高价值用户 + 跨场可信度
    →
    5**复盘**每场结构化 HTML 报告，结论可溯源
    →
    6**决策**对接预测市场，辅助挂单决策

  **核心信念：**价格先行，弹幕不预测价格；弹幕提供的是解释层、微观信息层与闭盘情绪层——这是信息差的来源。

  04 · TECH

## 轻量技术方案

### 只抓弹幕，不碰视频

WebSocket 直连聊天通道，数据量极小，可长期挂机。

### 自动重连

聊天服务器轮换时自动重连续写，今天单场自动重连 27 次零丢失。

### VOD 历史回捞

SOOP 回放带完整聊天记录，直播结束后可回捞全量历史弹幕。

### 韩文自动翻译

韩文弹幕全量中文化后再分析，情报输出为中文。

### 多直播间并发

一条命令同时开多个直播间，各自落盘互不影响。

### 已开源

虎牙弹幕采集器已发布 GitHub 公开仓库。

今天从零跑通全链路，并完整跟踪了 LCK 凯斯帕杯决赛 DNS vs NS（BO5，DNS 3:0 横扫夺冠）。

    10,593弹幕（不含回放样本）
    5路直播间
    2场赛事全程跟踪
    11份结构化报告

  **最有价值的一次命中：**赛前观众一致看衰 DNS 的 BP（"二队杰斯必败"），但赛后复盘发现——观众真正认可的是 **DNS 打野 shavel 的盲僧**（"世界第一野王""盲僧和其他九个不是一个档次的"），以及 **NS 三 FMVP 阵容的集体拉胯**（"两个 S 赛冠军 + 一个 MSI 冠军打成这样"）。判断层级比单场胜负深一层。
