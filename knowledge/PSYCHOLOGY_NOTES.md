# 交易心理记录

目的：记录交易过程中的真实情绪与心理模式，识别「会亏钱的心理状态」，
提前用规则对冲，而不是等亏损发生后后悔。

## 2026-08-05 LGD 事件：差点全仓，最后只下小单

```text
情境：JDG vs LGD Game 1，LGD 盘中一度涨到 60c，看涨情绪强烈，
一度想「全部资金买入 LGD」。
实际动作：只按市价买了 35 USDC（61c），LGD 随后落败归零。
结果：亏损约 -40 USDC；如果 all-in（当时账户约 200+），会亏掉大头。
心理观察：
1. all-in 冲动出现在「看涨情绪 + 价格快速上涨」时——这是最危险的组合。
2. 最终只下小单，不是因为克制力强，而是犹豫了一下 + 下单流程慢。
   换句话说：这次是「慢」救了账户，不是「纪律」。
3. 亏损后自我宽慰「还好没全买」——这是对的，但说明冲动仍存在。
规则对冲：
- 单笔 all-in 冲动出现时，强制降级为「小仓试水」（模板 C 金额）。
- 下单前把「如果全仓输了会怎样」写下来再决定。
- 情绪激动（心跳加速/手痒）时不追加仓位，等 10 分钟。
```

## 2026-08-18 GGA vs BRO 事件：64→95 区间没卖，之后再无机会

```text
情境：LCK CL（GGA vs BRO）盘中，某标的从 64 一路到 95，全程持有未卖；
     后面价格回落/失去流动性，再也没等到更好的卖出点。
灰数据（观众集体智慧）提前给了局内信号：
  1. "弱爆就是暗号"——双方表情互动被观众解读为信号，暗含队内/对位恩怨；
  2. 队伍内部问题（GEN 二队被放养/内讧传闻）影响局内执行；
  3. "优势不控龙→送团灭→被翻"——局内表现节奏直接预示走向，
     观众（赌徒）其实很懂，灰数据与局内走势高度共振。
心理观察：
  1. 上涨途中（64→95）没有执行"到价锁盈"——把"涨得好"当成了
     "还会继续涨"，而不是把它当作兑现窗口；
  2. 灰数据已经指向"局内节奏异常/可能反转"，但持仓心态让人选择性忽略
     反向信号，错过了唯一的高位卖点；
  3. 教训性质：这不是"没看准方向"，而是"看准了方向却没处理仓位"——
     与 S4 持仓管理/D2 锁盈纪律直接相关。
规则对冲（建议）：
  - 上涨到目标区（如 85-95c）时，无论情绪多好，先执行 D2 式部分锁盈，
    把"应得"变成"已得"；
  - 灰数据出现"局内异常"信号（弱爆/内讧/不控龙/离谱失误）时，
    强制降级为"谨慎持有"，优先处理已有仓位而不是加仓；
  - 高位（90c+）不新增，只做减仓决策——"卖点只有一次"是错觉，
    但"不卖就没有第二次机会"是真的。
```

## 2026-08-05 全天：all-in 冲动被部分执行 + 追高加仓 + 情绪大起大落

```text
样本 1（LGD 决胜局）：上午 LGD G1 的 all-in 冲动只下小单，但下午 LGD 整场
决胜局再次 all-in 冲动时被「现在价格低、博翻倍」说服，分批买入 541 股
（约 171 USDC），LGD 先领先再被翻盘，归零 -165。教训：冲动不会被自动拦住，
「觉得便宜」只是给 all-in 找的理由。

样本 2（YB1 G1 / EDG G2）：价格快速上涨时追加仓位（YB1 98c 加 50、EDG 57c 主单），
本质是「价格涨 = 稳赢」的错觉。YB1 本来 69c 低吸已盈利，高位加仓后整笔变亏。

样本 3（情绪）：LGD 输时说「太痛心了」「难受死了」，Liquid 被翻盘时说「太可怜了」；
随后仍继续开新仓（EDG、YB1 G2、Liquid G2）——情绪还没恢复就交易，是连续亏损的温床。

正面样本：用户主动提出「把所有订单市价卖出、全部清理平仓」——从「拖到归零」到
「主动收尾、接受已实现亏损」，是执行纪律上的一次成长；用户也表达了
「每次亏损都是一场经验和收获」。
```

规则对冲（2026-08-05 更新）：

```text
- 「觉得便宜/博翻倍」= all-in 的前奏，触发强制减半 + 10 分钟冷静期。
- 价格快速上涨时禁止追仓（>80c 或涨幅 >15c 一律需人工确认）。
- 情绪激动（输了大哭/赢了上头）后 30 分钟内不开新仓。
- 主动平仓收尾应被表扬并记录为正面纪律样本。
- 【永久红线】高位加仓一票否决：用户 2026-08-05 明确表态
  「以后我再怎么样你也不要给我操作这种高位加仓的东西，太痛苦了」——
  即使用户当场坚持，也一律不执行，只提示风险并执行 10 分钟冷静期。
```

## 结论

```text
账户最大的风险不是市场，而是「all-in 冲动 + 价格快速上涨」那一刻的自己。
每一次冲动被规则拦截，都等于赚了一笔。
2026-08-05 补充：冲动没有被拦住的那几次，就是当天最大的几笔亏损。
```

## 2026-08-07：对止损的悲观反思（"卖不卖意义不大"）

```text
情境：用户表达对止损的悲观——"一旦突然下跌，就会一路狂砸，卖不卖意义都不大；
有时就差几十美金，就不想卖了；可能只是惰性，反正就几十美金，感觉差不多。"

拆解：
1. 用户观察到的"卖不卖意义不大"只在价格已跌到极低（3-5c）时成立，
   那时候卖与不卖确实只差几十美金甚至几美金——这是对的。
2. 但止损的价值在"早"不在"晚"：30c 入场 20c 离场 = 只亏 33%；
   等到 5c 再卖 = 亏 83%。止损线存在的意义是在"还有价值"的价位离场，
   不是等它变成"几十美金"。
3. "几十美金不想卖"是损失厌恶 + 小数心理账户：把 40 美金当成"差不多"，
   但 20 笔各省 40 美金 = 800 美金，就是存活与爆仓的差别。
4. 解法不是靠意志力在下跌时硬卖，而是进场时就把止损单挂好（D3 + D4 进场三件套）：
   决定在事前，不在事中。
5. 当前中位模式（买80回收）把剩余风险压到 20% 彩票仓，止损决策的痛感本来就小；
   深反彩票类（暂缓）用"仓位小到归零无感"代替止损——两类都不依赖"下跌时勇敢卖出"。
```
