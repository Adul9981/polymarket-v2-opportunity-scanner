# V1.1 简单语言交易指令规范

最后更新：2026-08-04

## 1. 定位

本对话就是交易下单对话框。

用户用简单语言说明要买的方向和想法，系统自动完成：

```text
解析市场 → 匹配方向 → 生成计划 → 实盘挂单 → 监控 → 复盘
```

用户不需要提供市场 ID、token、订单参数等细节。

## 2. 用户输入模板

标准输入（推荐，信息最全）：

```text
链接：
目标：Game 1 / Game 2 / Map 1 / 整场
方向：队伍名或简称
策略：A / B / C，或一句自然语言
金额：可选，不填按默认
```

自然语言输入（同样可用）：

```text
这场第二小局我想买 DK，策略A。
这个 Game 2 像理财局，少量试一下。
帮我买这场比赛第一小局，按策略 A 执行，买 T1 方向，总投入 30 美金。
```

追加指令（一笔交易已建立后）：

```text
"止盈放在更高一点的位置"        → 调高止盈档位
"保留一定的彩票仓位"            → 加大 lottery_cost_basis_usd
"查状态"                        → 输出当前持仓/挂单/浮盈摘要
"关单"                          → 只撤未成交挂单，不卖已成交持仓
"平仓"                          → 卖出已有持仓（需明确表达）
"复盘"                          → 生成复盘并写入知识库
```

## 3. 系统自动执行流水线

```text
1. 解析链接 → 事件 slug（gamma-api.polymarket.com）
2. 定位子市场：Game / Map / Match Winner
3. 匹配方向：简称 → 正式 outcome；无法唯一匹配时用正式名称重试
4. 策略判定：A / B / C / D / P，或 auto 自然语言路由
5. 生成计划：买入档位、止盈档位、D2 锁盈计划、彩票仓
6. 执行前检查：风控限额、市场可下单、不重复买入
7. 实盘挂单：分层 BUY；成交后自动补 SELL
8. 监控接管：monitor-only，不新增买单
9. 状态 / 关单 / 复盘
```

核心入口：

```text
tools/prepare_grid_trade.py    生成计划 + 五个本地入口
runtime/run_*.command          首次执行（挂单 + 进入监控）
runtime/monitor_*.command      monitor-only 接管
runtime/status_*.command       只读状态摘要
runtime/close_*.command        撤未成交挂单
runtime/review_*.command       生成复盘
```

## 4. V1.1 默认规则（D2 自动锁盈）

```text
60c 以上开始回收本金。
75c 以上锁定主要利润。
80c 以上只保留小彩票仓。
```

彩票仓上限：

```text
原始成本的 10%-20%，或固定 5-15 USDC，取更小值。
```

高位回撤保护：

```text
触达 75c 后回撤到 68-70c，保护主要剩余仓。
触达 80c 后回撤到 72-75c，保护主要剩余仓。
```

## 5. 风控与纪律

```text
单市场默认 ≤ 30 USDC；单日 ≤ 75 USDC。
已有状态文件时不重复买入，只进入监控。
关单 = 撤未成交挂单；平仓 = 卖出持仓。两者不可混用。
不追高：A 型只在 20-30c 深度区间接回落单。
部分成交后保留已成功订单状态，进入 monitor-only 管理。
每笔交易默认保留 10-20% 彩票仓：止盈梯只覆盖 80-90% 仓位，
彩票部分不挂止盈卖单，持有到结算或极高价位（2026-08-04 起执行）。
止盈配对规则（2026-08-05 起执行）：每一批买入（按成本价区分）成交后，
立即按「该批成本 +12~15c」配对挂出止盈；止盈必须高于该批成本和当前市价，
绝不混用其他批次（尤其高位批次）的止盈档，避免出现「止盈低于市价一挂就成交」的错配。
下单前先按信心级别选择执行模板（docs/framework/STRATEGY_PATTERN_LIBRARY.md 第 10 节）：
普通「看好」→ 模板 B（赛前少量 1/3 + 赛中挂单低吸）——默认执行；
明确「信心非常足」→ 模板 A（赛前仓最多 40-50%，不重仓 + 低吸放极端低位 + 移动止盈 + 不追高 + 不市价割）；
微微看好 → 模板 C（小仓、高止盈拿久）。
注意：所有模板赛前仓一律不超过 50%（2026-08-05 起，昨日尾盘亏损教训）。
```

## 8. 订单真实性验证（2026-08-05 可靠性教训）

背景：接口抖动时，下单接口可能返回「success / live」，但订单实际没有持久化（查询状态为 INVALID）；
同时 open-orders 查询也可能静默返回空，容易被误读为「全部成交」。

规则：

```text
1. 每笔挂单后必须验证：用 get_order(订单号) 确认状态不是 INVALID/不存在；
   INVALID = 没挂上 = 按失败处理并重新挂单。
2. open-orders 查询为空 ≠ 无挂单：查询失败会静默返回空。
   用 tools/check_open_orders.py 确认（该工具失败会大声报错并非零退出）。
3. 遇到 SSL EOF / Server disconnected / request error 时，默认认为操作可能没生效，
   重试并验证后再进行下一步；不要直接断言「已成交」或「无挂单」。
4. 执行器 tools/grid_plan_runner.py 已内置下单后核验（INVALID 自动标记失败）。
5. 手工挂单同样遵循：挂完用 check_open_orders.py 复核订单号在列。
```

## 8.1 价格来源纪律（2026-08-05 起强制）

背景：gamma 的 outcomePrices/bestBid/bestAsk 经常严重滞后（实测可落后 20c+），
多次出现「按 gamma 快照价格决策，实际 CLOB 盘口完全不同」的情况。

规则：

```text
1. 执行价格唯一依据 = CLOB 实时盘口（get_order_book 的 best bid/ask）
   + get_last_trade_price + 账户最近成交记录（真实成交价），三者交叉核对。
2. gamma 只用于：确认市场是否存在、子市场 ID、outcome 名称、成交量/流动性、
   是否 closed——绝不用 gamma 的价格字段做任何下单决策。
3. 下单前连续拉 2-3 次 CLOB 盘口，若两次读数一致才执行；
   若 CLOB 与 gamma 偏差 > 2c，以 CLOB 为准并记录偏差。
4. 实际成交价以 fill 记录为准（可能比挂单价更好），成交后立即读 fill 价格
   并据此配对止盈，不要用挂单价或快照价算止盈档。
5. 用户看到 App 价格与我的报价不一致时，先重新拉 CLOB 实时盘口再回复，
   不争辩"我以为"。
```

## 8.2 高位加仓一票否决（2026-08-05 用户强约束，永久生效）

```text
定义：高位加仓 = 现价 > 80c，或现价相对本场最近低点涨幅 > 15c 时新增买入。

规则：
1. 触发高位加仓条件时，无论用户如何坚持，一律不执行买入，
   只回复价格与风险提示（最多 3 行），等待用户确认「已知风险仍要买」以外的话。
2. 若用户仍明确要求，先执行「10 分钟冷静期」：不立刻下单，10 分钟后再复核价格；
   多数情况下价格回落或用户改变主意。
3. 用户自己手动下单不受本规则约束，但系统不主动替用户挂高位买单。
4. 复盘案例：YB1 G1 98c 加仓 50 使胜局转亏、EDG 57c 主单、LGD 决胜局追买——
   三笔全部高位加仓致亏，用户亲述「太痛苦了」并主动要求永久禁止。
```

## 8.3 小额止损豁免（2026-08-16 用户强约束，永久生效）

```text
规则：当止损可回款金额 < 5 USDC 时，不做止损（不卖出），保留仓位当彩票。

背景：BRO G2 崩到 2-4c，仓位市值约 2-4 USDC，止损回款不足 5 美金，
卖出与否几乎无差别；用户明确「卖不卖无所谓，还不如不卖」。

执行含义：
1. 先估算止损回款 = 持仓股数 × 当前 bid；< 5 USDC → 跳过止损，持仓保留至结算。
2. 若用户要求「买回来」= 保留/不卖，不执行市价割肉。
3. 仓位归零也接受（小额彩票性质），不再重复追问。
```

## 6. 复盘闭环（知识库）

每笔交易结束后，把结果写回知识库，供后续交易参考：

```text
python3 tools/append_knowledge_review.py \
  --state-file <状态文件路径> \
  --result "<最终结果>" \
  --lessons "<教训要点>"
```

知识库位置：

```text
knowledge/README.md
knowledge/TRADE_REVIEW_TEMPLATE.md
knowledge/reviews/index.md
```
