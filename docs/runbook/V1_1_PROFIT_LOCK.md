# V1.1 升级：D2 自动锁盈

日期：2026-08-03

## 1. 核心结论

V1.1 的最高优先级是：

```text
自动指引并快速锁定利润。
```

系统不是为了赚到最后一分钱，而是为了防止把已经赚到的钱还回去。

## 2. 背景案例

NS vs T1 Match Winner 暴露的问题：

```text
低位买入是对的。
部分止盈也是对的。
但剩余仓位在 75c-80c 大额浮盈时没有继续锁定。
最后电竞尾盘快速反转，剩余浮盈和本金几乎全部还回去。
```

这不是单纯策略判断问题，而是执行纪律问题。

## 3. D2 定义

```text
D2：浮盈保护 / 自动锁盈
```

D2 不是新的入场策略，而是执行保护模块。

适用：

```text
A：深度反转 / 彩票型
B：强队临时低估 / 热门回撤
C：强势碾压 / 理财局
P：赛前小底仓
E：BO3/BO5 整场反转发现标签路由后的 A / A2 / B2 仓位
```

## 4. 默认规则

如果平均成本在 20c-35c，默认锁盈：

```text
60c-65c：至少回收本金。
70c-75c：锁定主要利润。
78c-82c：只保留小彩票仓。
```

彩票仓上限：

```text
原始成本的 10%-20%
或固定 5-15 USDC
取更小值
```

V1.1 默认配置：

```text
trigger_min_profit_price: 0.60
major_lock_price: 0.75
final_trim_price: 0.80
max_lottery_cost_basis_usd: 10
max_lottery_cost_ratio: 0.20
```

高位回撤保护：

```text
触达 75c 后，回撤到 68c-70c，要保护主要剩余仓。
触达 80c 后，回撤到 72c-75c，要保护主要剩余仓。
```

## 6. 产品原则

```text
低位买入后，60c 以上开始回收。
75c 以上必须锁定大部分。
80c 以上只允许小彩票仓。
剩余仓位如果还能明显影响心态，就不是彩票仓。
```

## 7. 任务优先级

```text
最高优先级：成交后自动挂锁盈单。
第二优先级：剩余仓位超过彩票仓上限时，自动提示或自动减仓。
第三优先级：高位回撤保护。
第四优先级：继续优化机会发现层。
```

## 8. 和 E 型发现标签的关系

```text
E_BO3_SERIES_COMEBACK 不是新的出场规则。
它负责发现 BO3/BO5 Match Winner / Series Winner 中的整场折价修复机会。
一旦 E 型路由到 A / A2 / B2 并发生买入成交，D2 必须接管后续浮盈保护。
```

执行口径：

```text
第一档成交后，不能只理解为“挂一个普通止盈单”。
正确口径是：
第一档成交后，先挂基础止盈；
同时进入 D2 暴露检查；
价格到 60c 以上开始回收；
价格到 75c-80c 后，只保留固定小彩票仓。
```
