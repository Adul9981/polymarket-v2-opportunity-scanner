## 追加检验（2026-08-15 第二轮）："有去有回"全剧本假设

用户提出：若为标准假赛，组织者应有"有去有回"——同一批账户买中
G1（VIT）+ G2（GX）+ 整场（VIT）三个赢家。已全量扫描并做对照组。

```text
方法：只看定局前买入（分钟级价格定局：G1 17:19 / G2 18:18 / 整场 19:08 UTC），
每腿 >= $100；对照组 = 同日 LPL AL vs JDG（同样 2-1，定局 G1 12:06 / G2 12:56 / 整场 13:56）。

结果：
  三腿全买中账户：嫌疑场 22 个 vs 对照组 74 个（对照组反而多 3.4 倍）
  赛前三腿全买中：嫌疑场 2 个（合计约 $2.1k）vs 对照组 1 个（antec，$2.4k；
  注：早期稿误算对照组开赛时间为 13:15 曾得 20 个，已修正）
  独立随机基线富集：嫌疑场 12.0x vs 对照组 19.1x
  两场出现大量相同地址（antec / 0x9e3ed7b6 / suntori / Jimmyman132 / cryptolava 等）
  -> "全剧本"是这批电竞盘口玩家的常规打法，非本场特有内幕信号。

嫌疑场 22 个全剧本账户的腿细节：
  V1 腿：几乎全部在 17:02-17:14（VIT 碾压时）以 0.61-0.75 追买（局中跟随）
  整场腿：在 18:05-19:08（VIT 领先时）以 0.60-0.95 追买
  G2 腿：深水机器在 0.10-0.18 抄底（与历史一致）或赛前 0.40-0.45 押下狗
  唯一赛前三腿买齐的 0x0d2d845a：三腿合计仅 $1.5k（G2 腿 $278），局中还有大量反向交易
```

结论：**"全剧本"形态存在但不异常——嫌疑场的全剧本账户数量低于正常比赛**，
且赛前三腿全买在两边都几乎不存在（2 vs 1），与"赛前预知三局结果"的组织者画像不符。
公开成交数据层面，假赛组织者没有留下"赛前重仓三腿"的痕迹。
