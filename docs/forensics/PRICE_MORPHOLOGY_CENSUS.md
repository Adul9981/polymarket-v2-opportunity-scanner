## 四、形态族解读（数据告诉我们的规律）

```text
1. 阴跌归零是最大族（L2 183 条）：其中"中开/高开 + 晚段才死"占 123/183——
   即开局定价不低的队伍，很多是慢慢磨到 0，而不是瞬间崩；
2. 直通上行（W1 153 条）在高中低开分布均匀（46/41/40）：
   直通与开局价无关，关键特征 = 早段（<33% 赛程）不回头（低点都在"早"）；
3. 深V反转（W3 99 条）集中在"高开 + 中/晚段见低点"（25+29）：
   反转不是深水抄底者的专利，更多是强队盘中深跌后的修复；
4. 快崩（L3 42 条）86% 是"低开早崩"（36/42）：开局就低于 0.20 的，
   大部分不是等反转，而是等死（快慢之别）；
5. 冲高回落（L1 130 条）主要从低开/中开冲高后死亡（28+29+14）：
   低价反弹到 0.5-0.6 再归零是常见陷阱，对应"接反弹刀"的风险。
```
