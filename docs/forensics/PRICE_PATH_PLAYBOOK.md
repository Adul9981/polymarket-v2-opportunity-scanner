## 0. 一句话

买入只是开始。任何一笔电竞盘口买单（0.2~0.65 价带），买入后价格只可能走"下面 7 种路径"之一。
本手册把每条路径的**识别特征、应对动作、止损/止盈参数**提前定死；盘中只认路径、切模式，不临时决策。

前身：S-F5（djdjdjekekek 的 0.2-0.4 强队价值买入）只回答了"买什么"（ROI +12.9% 的选边区）。
本手册补上另一半："买入后不管走哪条路，动作都提前定好"——因为那个账户崩盘的原因不是选边，
而是无退出：227 个仓位持有到归零、从不主动止损。

## 1. 路径全集（只有这 7 条）

路径会复合：一场价格序列经常是几条路径的拼接（例如 P3 深V 反转前先经历一段 P5 式阴跌）。
所以路径不是一次性分类，而是状态机——下面每条路径的"动作"会在路径切换时跟着切。

| --- | --- | --- | --- | --- | --- |

## 2. 五种交易模式（路径 → 动作）

| 模式 | 适用路径 | 动作集 | 触发/退出条件 | 模块 |
| --- | --- | --- | --- | --- |
| A 持有上行 | P1、P2 上行段、P3 反转段 | 持有 + D2 锁盈梯：60-65c 回收本金、70-75c 锁主利、78-82c 只留彩票仓（≤成本 10-20%）；移动保护：触 0.75→0.68、触 0.85→0.78 | 价格在止损线上方，回踩不破保护线 | D2 |
| B 回踩管理 | P2 回踩段、P3 深跌段（止损线上方） | 停止新加仓；已有止盈单继续；允许部分减仓；深跌段只做"启动确认"（低点后首次反弹 + 二次探底不破前低 + 距结算 ≥15 分钟 + 独立新预算）后才允许小额补仓（≤彩票仓上限） | 回撤 8c+ 且未破止损线 | S4 + D3 C→重评估 |
| C 冲高锁盈 | P4 全程 + 任何路径进入 0.70+ | 0.62-0.65 回收本金 → 0.70-0.75 锁主利 → 0.78-0.82 只留彩票仓；高位（0.85+）出现反转信号立即执行移动保护，不"再等等" | 触及止盈梯任一档，或高位反转信号（弹幕/解说质疑、流动性骤降） | D2 移动保护 |
| D 止损退出 | P5、P6、P3 破止损线 | 跌破成本一半 → 无条件离场；比赛末段（最后 5-10 分钟）仍未反弹 → 时间止损离场；离场后按 D3 重评估（独立新预算、成本不继承），符合 S1-深反/S1-标准/S2 模板才重新进场；崩塌后不接飞刀 | 价格 ≤ 成本×0.5，或末段未反弹 | D3 + D4 |
| E 横盘等待 | P7 | 不动作、不加仓；每 10 分钟或末段前检查一次；向上破位 → 切 A；向下破位 → 切 D | P0±10-15c 内无突破 | D3 状态 B（保护带） |

用户视角对照（先涨/先跌）：

```text
先跌后涨 = P2(first=down) / P3 深V   -> 模式 B（停加仓、等启动确认）-> 确认后转模式 A
先涨后跌（跌不归零）= P2             -> 模式 C 已锁盈，回落不破保护线则模式 A 继续
先涨后跌（跌到归零）= P4             -> 模式 C 没锁够 = 教训；锁盈后由模式 D 兜底
直接涨 = P1                          -> 模式 A（D2 自动锁盈）
直接跌 = P5 / P6                     -> 模式 D（事前挂止损单，崩塌不接飞刀）
横着不动 = P7                        -> 模式 E（时间检查，破位切 A/D）
```

例：赛前 46c 开牌、60c 买入，止损线是 30c（60c 的一半），不是因为"从 46 看到 60"就可以放宽。

市场分层：

```text

  第三局起没有独立小市场，只能走 Moneyline。
```

## 5A. 路径形态学分类（前瞻版）：局中如何判断"这场比赛正在走哪种形态"

买入时机**。本节给分类本体与局中识别特征；执行规则见 5B 预览。
