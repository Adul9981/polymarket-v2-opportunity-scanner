# 策略库：从交易者拆解中沉淀的可复制策略

最后更新：2026-08-21

本库登记从外部交易者（当前：e46m3）拆解出的、有可能被本项目复制的策略。
每条策略带证据、参数与成熟度。成熟度沿用项目框架：

```text
L0 观察 -> L1 建议 -> L2 回测/模拟 -> L3 小额实盘 -> L4 稳定实盘
未到 L2 之前只登记、只建议，不进入任何实盘路径。
```

## S-F1 完整集定价套利（Complete-Set Arbitrage）

核心：检测负风险多选项组的完整集定价 Σp 偏离 $1，买入被低估的一侧，
用 Convert/Merge 立刻兑现价差（不等结算）。

### 方向 A：Σp > 1（买 NO 组合 -> Convert）

```text
触发：Σp_YES > 1 + 阈值（吉达实测偏离 4.7%~6.4%，阈值待定）
步骤：
  1. 扫组内各档 YES 价格，计算 Σp；
  2. 以市价/限价买入 NO 组合（价格低于理论值 (1-p_i) 的档）；
  3. Convert：NO 组合 -> 现金 (n-1)X + 补集 YES；
  4. Merge 可配对的 YES+NO，或把补集 YES 卖出/留存；
  5. 循环，叠加做市返佣。
单轮毛利：≈ X × (Σp − 1)
```

证据（吉达 8/12 温度组，13 次 Convert）：

```text
每次 Convert 时点 Σp = 1.0475~1.0640
00:22:04 那笔：NO(35~41°C+ 共 7 档) -> YES(31~34°C 共 4 档) + $23.48 现金
链上交易：0x213f98a8867a9cc77a6c0fef36a2d2f91732070f2a9a9b0633ef06b3696a27f8
```

### 方向 B：Σp < 1（买 YES 完整集）

```text
触发：Σp_YES < 1（尚未在该地址数据中实测，观察中）
步骤：买入全套 YES（价格合计 < $1）-> 持有到结算 Redeem / 或组内 Merge
```

### 参数与风险

```text
适用市场：负风险多选项组（温度档、比分盘、冠军未来盘、选举）
观察参数：Σp 偏离阈值、单轮金额、循环频率、返佣贡献占比
e46m3 实测风格：单笔中位 $0.70，10-100 区间为主；全天 24×7
风险：
  1. 盘口薄 -> 买入价高于报价价（滑点吃掉价差）
  2. Σp 快速回归 -> 未及时出手则套利空间消失
  3. 结算前极端行情 -> 边缘档价格剧变
  4. 返佣依赖 -> 无返佣时毛利可能不覆盖成本
成熟度：L1 建议（1 个完整案例；升级 L2 需 ≥3 场 + Σp 回测）
```

## S-F2 做市返佣叠加（Rebate Farming）

```text
核心：在长尾市场 24×7 挂双边小单，赚做市/吃单返佣 + 平台奖励，Convert/Merge 用于清库存。
证据：e46m3 近 100 笔返佣+奖励合计 $2,546；活动 24 小时无空窗。
成熟度：L0 观察（返佣规则需平台文档确认；本项目当前不追返佣）
```

## S-F3 尘埃尾差清理（Dust 管理）

```text
核心：用极小额 Convert/Merge 清掉拆分/合并留下的尾差，保持仓位干净。
证据：e46m3 在 MLB 冠军盘 157 次转换中位仅 $0.02；吉达组穿插大量 ≤$0.01 操作。
价值：低（主要是卫生），不是利润来源；复制优先级最低。
成熟度：L0 观察
```

## S-F5 强队价值买入（0.2-0.4 价带，账户级观察）

核心：买"判断为强、但盘口只给 20-40¢"的队/选手，赢后按 ~$1 赎回或
0.999 卖出；单场 2.5-4 倍赔付，31.8% 命中率即可正期望。

证据（djdjdjekekek 账户深拆，2026-08-20）：

```text
0.2-0.4 价带：85 事件 / 27 胜，买入 $7.52M，净 +$968K，ROI +12.9%
代表事件：MLB 红袜两连 +$1.06M（@0.24/0.39）、Dota2 Liquid/Falcons +$1.03M（@0.38）、
          世界杯 Spain +$426K（@0.29）、网球 Molcan +$655K（@0.35）
退出：赢定后 0.999 卖出/赎回（该账户 88% 卖出金额在 ≥0.8 价带）
```

关键边界（决定可复制性）：

```text
同一价带在不同赛项结果相反：MLB +$976K / 其他 +$853K / 网球 +$531K 为正，
CS2 -$1.04M / Dota2 -$287K 为负 -> 模式的前提是"该赛项有判断力"，
跨赛项复制 = 失效（djdjdjekekek 在 CS2 EWC BO1 + Dota2 TI 小组赛四天亏 $2.62M）。
```

风险与纪律：

```text
1. 单场全仓 + 无止损：该账户 227 个仓位持有到归零。
2. 与项目 S1 深水抄底机器的区别：S1 靠高频微利 + 小仓，本模式是单场重仓价值判断，
   资金需求与风险完全不同。
成熟度：L0 观察（样本 = 1 账户 / 85 事件；需项目按赛项分域回测，
建议优先 MLB / 网球 / 世界杯等"强共识"赛项）。
```

## S-F6 价格路径交易模式（买入后全路径管理，2026-08-21 登记）

核心：把"买入后"的管理从临时决策变成状态机。任何 0.2~0.65 价带的电竞盘口买单，
价格只可能走 7 条路径（P1 直通上行 / P2 回踩后上行 / P3 深V反转 / P4 冲高回落归零 /
P5 阴跌归零 / P6 快速崩塌归零 / P7 横盘），每条路径对应 5 种交易模式之一
（A 持有上行 / B 回踩管理 / C 冲高锁盈 / D 止损退出 / E 横盘等待），动作与参数事前定死。

证据（2026-08-21，77 场已归档比赛 / 664 条可用价格序列，1/5 分钟粒度，
定局 = 价格钉在 0/1 的时刻；入场点采样 = 每 10 分钟进入价带一次，序列-价带上限 15）：

```text
0.20-0.40 买入：最终上行 1365/3381（40.4%）；分赛项 LoL 46.3% / CS2 20.6% / Dota2 45.3%
0.40-0.55 买入：最终上行 2367/4992（47.4%）
0.55-0.65 买入：最终上行 1932/3184（60.7%）；79% 摸到过 0.75+（锁盈机会几乎必然出现），
  但 63% 也跌破过 0.40（模式 B 回踩管理是常态，45% 会跌破 0.20 触发成本一半止损评估）
```

参数与纪律：

```text
止损一律 = 成交成本的一半（60c 买入 -> 30c；按成交价算，不按"我看到的更低价"放宽）
止盈按分区：0.2-0.4 卖高留低（50/70/85/95）；0.4-0.55 62/75/88+10% 彩票；
            0.55-0.65 62-65 回本 / 70-75 锁主利 / 78-82 留彩票；>0.65 不追
加仓只在"启动确认"后（低点后首次反弹 + 二次探底不破前低 + 距结算 >= 15 分钟 + 独立新预算）
全部沿用 D2/D3/D4/D6 模块，不新增独立阈值
```

成熟度：L1 建议（77 场/664 序列方向性证据 + 50+ 场复盘质性样本；
升 L2 需按联赛与开赛前后分域、每笔复盘打路径标签、完成模拟回测）。
2026-08-22 更新：加入**前瞻形态学分类**（80+ 场 / 710 序列，比赛窗口口径）——
6 种整场形态的局中签名（开局价/最大回撤赛程点/回升）+ 局中价格带->最终形态表
（25/50/75% 赛程）+ 0.2-0.4 首进前瞻分布；结论 = 0.2-0.4 是"陷阱区"
（50% 赛程后上行 24.4%，主流 S5/S4），只有"局内高位跌入 + 首动 up"（47.3%）
与赛前价值位（42.4%）可买；工具 tools/path_morphology_live.py；
手册 docs/forensics/PRICE_PATH_PLAYBOOK.md 5A/5B。

## 复制门槛与纪律

```text
1. 我们复制的是"现象 -> 规则"，不是照抄他的仓位与频率。
2. 任何 S-F 策略进入实盘前必须：≥3 场同模式案例 + Σp 回测通过 + 走项目成熟度/风控。
3. 执行仍遵守项目红线：方向无歧义、不碰私钥、固定金额制、先 dry-run。
4. 每场拆解结论必须回流本库：更新样本数、成熟度、参数或登记新模式。
```

### S-F1 复制可行性判断（2026-08-12）

```text
检测层（已具备）：Σp 实时计算、三案例（天气/足球/棒球）已验证，可建只读扫描器。
执行层（缺口）：
  1. Convert/Merge 是链上合约操作，当前 polydata 钱包项目只有买卖网格接口，
     无转换/合并能力；补齐需改 polydata（用户决策 + 显式授权）。
  2. 边很薄：单轮净利约 X 的 3%~7%（占投入资金约 0.5%~1.5%），依赖小单高频；
     流动性天花板低（目标账户单笔中位 $0.70），大资金会吃掉价差。
  3. 真实净盈利未完全证实：现有数字为估算（含返佣），需模拟验证。
升级前置（L1 -> L2）：
  1. 只读 Σp 扫描器跑两周，统计窗口频率/持续时间/可成交性；
  2. 用价格历史做模拟回测（买 NO @ 中间价 + Convert + Merge），
     计入滑点假设后看净期望；
  3. 回测为正、用户确认、风控放行后才进入执行开发与小额试点。

结论与门槛（2026-08-17）：

```text
1. 结构边真实存在（Σp 长期偏离、机会频率高），但厚度很薄：
   毛利约 (Σp−1)X，占投入资金仅 ~0.3%，1% 滑点即可吃掉大半。
2. taker 全收费、无返佣口径下回测为负 -> 按"回测不为正不模拟"纪律，
   S-F1 停留在 L1，不进入模拟/实盘路径。
3. 升 L2 的前置改为：
   a. 订单簿历史数据校准真实可成交成本（标记价 + 滑点假设精度有限）；
   b. 平台返佣/做市规则确认（S-F2，2026-08-15 实测 Convert 0 bps 只是第一步）；
   c. 用扫描器跑满两周，统计 Σp≥4%~5% 的窗口频率（e46m3 实际只吃这种）。
4. 若上述验证通过，参考口径：滑点 ≤50bps + 返佣覆盖手续费时才有正期望。
```
结论：流程可复制，利润不可保证；先用只读工具验证，再谈真实资金。
