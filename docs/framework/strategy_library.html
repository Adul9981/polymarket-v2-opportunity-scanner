策略总清单

分类按"实证来源 + 交易主战场"：小局第一、整局第二、通用/特殊收尾—— 你的大部分真实交易与复盘来自小局，所以小局策略排在最前。每项带三档颜色定位（操作姿态，不是判断对错）。

🟢 常规做正期望 + 已实盘多次验证 + 可半自动（主攻）
🟡 谨慎做逻辑/回测成立，实盘样本不足或需严格纪律（小仓验证）
🔴 不做或先验证负期望（规则性不做）或完全未验证/暂缓

彩票机器 NEW

从"深跌反转"现象提炼出的完整入场策略：第一层极低价挂单自动覆盖，第二层反弹确认加仓不接刀。 2026-08-08 回测完成——层 1 反转场次平均 8.3x，层 2 主触发 ROI +91%。

现象A1 V 型极值反转→ 策略两层触发 + 止盈止损→ 验证1 分钟回测→ 下一步小额实测 20-30 触发

小局策略

Game / Map Winner · 你的主战场
大部分真实交易、复盘与回测来自小局；整场 Moneyline 的适用性在卡片内标注。
🟢 常规做赛中

热门回撤接（S2）

热门 ≥65%，70-80c 浅回撤最优、60-70c 次优、40-50c 主攻；跌破 40c 失效转 S1（原 S3 已并入）。
证据：130 场统计（70-80% 胜率 96.7%）；BESTIA · NRG +25.4 · LNG/IG +37 · T1A
整场同样实证：NAVI +33.5% · HLE 整场 +34.8 · BetBoom +28
注意：热门无回撤场次（KT/GEN、JDG/EDG 最低 62-82c）= 低交易价值，45c 挂单不触发属正常
🟢 常规做赛中

中位反转-标准（S1-标准）

20-50c 深跌分档接，买80回收（60-70c 卖 80% 成本 + 20% 彩票）。
证据：BO3 首局落后样本（G1）；08-05 接刀反面（无方向过滤不可做）
整场版：P5 E-A2（SPARTA 33.5c）
🟡 谨慎做赛前/开局

五五开局早买

50-60c 小仓压一方拿资格，>60c 不追；全仓版本 = 高风险样本，不进系统。
证据：T1/DK +200（全仓，反面纪律）· T1a 赛前 63c +5.4 · BFX 赛前 All in（反面）
🔴 暂缓赛中

中位反转-深反（S1-深反）

<15c 彩票仓，金额随价格下降递增，吃倍数。暂缓（设计/模板/回测保留）。
证据：WE G1 6.5c · WE G2 0.65c · IG/NIP <5c · BRO G1 1.5c→99.95c · K27 整场 6c→100（CS2，08-09）· GEN/DNS 整场 5.5c→92.5（08-10）
整场同样出现：VG/YB 7c · WE/AL Moneyline · HLE Challengers Moneyline 5.5c
🟡 谨慎做赛中

反弹确认加仓

<10c 低点单根拉升 ≥10c 后追确认仓，不接刀（彩票机器第二层，回测完成，待小额实测）。
证据：回测 4 触发平均 +13.7/笔（ROI +91%）· WE G2 13c 上车 +425% · FOKUS G1 9c→99.95（CS2 首证）
回测以 小局 为主（WE/BRO/TES/FOKUS G1）
🟡 谨慎做赛中

中位震荡多轮网格

25-75c 反复穿越 50%，多轮低买高卖（未实盘，先模拟验证）。
证据：GLYPH G2（10 次穿越）+112.6%
整场也出现：SPARTA / VG/YB / WE-TT Moneyline（5-7 次）
🟡 谨慎做赛中

CS 局内落后侧

CS 回合/半场暂时落后 ≠ 输，买落后那一侧（CS 回合制专属）。
证据：Liquid G1（60/55/50c 低吸后 Map 翻盘）· 9INE 为反面

整局策略

Match / Series Winner · Moneyline 专属
只在 BO3/BO5 整场市场成立；你目前对这些主要是分析/回测，实盘样本少于小局。
🟡 谨慎做首局/前半段落后

系列赛翻盘（P5）

Moneyline 折价：<30c 走深反 · 30-45c 走中位 · 55-70c 走热门回撤。
证据：VG/YB +196% · SPARTA +34.7% · NAVI +33.5% · WE/AL · HLE Challengers · K27 整场 6→100（CS2 让一追二）· DNS 整场 11.5→100 · HLE 整场 11.5→100（08-10） · RE 整场 17.5c 深水区（Dota2，08-11）· LevelUP 整场 9.5→100（Dota2，08-11）· DK 整场 1.5→100（NSEA/DKC，LCK CL，08-11 让一追二）
🟡 谨慎做Moneyline 低开

下狗整场反转早买

Moneyline 低开（20-35c 甚至 <10c）→ 下狗确认反转早买区 35-45c；G1/G2 逐局抬升。
证据：TT 27.5→99.95 · TES 14.5→100 · WE/AL Moneyline 13.5→100 · BRO Moneyline 21.5→100 · DNS 11.5→100（DNF 让一追二）· DNS 5.5→92.5（GEN 弱克强，08-10）· DK 1.5→100（NSEA/DKC，08-11 让一追二，样本组最深）
🟡 谨慎做BO3 1:1 / BO5 2:2 后

决胜局结构

只允许赛前底仓 + 20-30c 小彩票；40-50c 破位禁止加仓；大优时 60c+ 必须预设止盈。
证据：BRO vs DRX G3（五错 -60）· WE vs TT G3（WE 11.5c→0.05c）
🟡 谨慎做BO3 首图落后

CS 首图落后整场翻盘

买暂时落后侧（整场版，P5 的 CS 形态）。
证据：SPARTA 首图落后 → 整场赢
🔴 纪律整场持有

死亡螺旋纪律

热门近胜被翻后 Moneyline 一路归零（BFX 75.5→0.05 · BLG 85.5→0.05 · NS/T1 79.5→0.5）。G1 被翻后整场仓应减仓/止损（D3），不留着赌 G2。
非入场策略：D3 止损的应用场景；第三局起只有 Moneyline，无独立小市场

通用策略

小局 + 整场都适用 / 实证
赔率结构类策略：小局开盘和整场开盘都能用，两边都有样本。
🟡 谨慎做赛前

三七开买 3（冷门底仓）

30-40c 小底仓，赛中跌深再接力 S1。
证据：NS G1 35-40c（小局）· BRO 决胜局 Moneyline 赛前 40c（整场）
🔴 不做或先验证赛前

三七开买 7（热门侧）

负期望规则：65-80c 直接买不成立，只能等赛中回撤。胜率不低但价格已透支。
证据：HLE 77c 归零（整场，期望 -11.7）· YB1 78.2c 全仓侥幸（小局）
🟡 谨慎做赛中（一方被错杀）

强强对话价值买入（A7）

双方实力接近（赛前 45-55 分）+ 一方被砸到 <30c → 反转买入（S1-标准 / 彩票仓）；联赛信誉过滤：LCK/CS2 适用，LPL 降级。
证据：PHA 13.5c（CS2 EYE/PHA）· HLE G2 22-25c（08-08 翻盘赢系列赛）· TT 27.5c · TES G1 4.5c · BRO G1 1.5c · K27 Map2 11c（CS2）· HLE1 Moneyline 11.5c（LCK 让一追二，08-10）；反例 BLG/TES（LPL）

特殊策略

结构特殊 / 持仓管理
🟡 谨慎做彩票池

彩票机器

两层触发（极低价挂单 + 反弹确认），现象→策略→回测完成，待小额实测。见顶部高亮卡。
证据：层 1 反转平均 8.3x · 层 2 主触发 ROI +91%
🟡 谨慎做持仓

对冲保护

小额买另一侧做保险，单笔 ≤ 预算 10-20%，可归零。
证据：HLE G2 8c 买 5 美金保险
🔴 先验证持仓

持仓救援（S4）

已有亏损仓：先降险、不默认补仓；形态符合 S1/S2 才小额补仓。
证据：08-05 部分止盈后归零

执行模块

不算策略，但必须遵守
D2 锁盈：尾盘崩塌/尾盘极限反转保护（60 回收 / 75 锁利 / 80 彩票）
D3 止损：跌破成本一半离场；死亡螺旋后整场不留赌 G2
D4 进场三件套：先挂止盈/止损/彩票上限再买入
D5 信心溢价：纯主观单按彩票仓定规模（≤10-20%）
D6 每日回吐：到线停止新开仓
滚动降成本：高位卖、低位接（动作，不是策略）
