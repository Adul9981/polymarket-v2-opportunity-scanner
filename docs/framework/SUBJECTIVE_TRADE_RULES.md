# 主观交易纪律化规则清单（2026-08-18 定稿）

> 来源：用户复盘洞察——"大部分盈利基于主观判断（判断哪队会赢，
> 通过赛前/赛中/赛后买入、加仓、调仓获利），但大量亏损也来自此。"
> 定位：不否定主观判断，它仍然是方向来源（用户的优势）；
> 规则接管"仓位 / 加仓 / 调仓 / 止损 / 止盈"（用户的亏损缺口）。

## 0. 一句话原则

```text
主观定方向，规则定仓位；判断可以错，仓位不许错。
```

## 1. 交易模式：主观交易（S0-SUBJECTIVE）

```text
适用：用户对某场比赛/队伍有方向判断（赛前情报、队伍状态、局势阅读）。
与 S1/S2 的区别：
  S1/S2 是"现象路由策略"（价格触发 -> 模板网格）；
  S0 是"主观方向 + 规则仓位"（人判断方向，规则管风险）。
两者可叠加：主观看好 + 价格跌到 S1/S2 区间 = 双确认，可上量；
只有主观、无价格结构 = 默认小仓（探测），不上量。
```

### 主观判断分级 -> 仓位映射

```text
L1 普通看好（"感觉会赢"）        -> 探测仓 ≤10u（或 ≤30% 的 1/3）
L2 高信心（情报/状态/局势有依据） -> 标准仓 ≤30%（30u 账户 = ≤9-10u）
L3 双确认（高信心 + 价格在 S1/S2 区间）-> 标准仓 + 允许一次加仓
任何级别：全仓一票否决；账户恒 ≤30u，钱包 60u 永不入场。
```

## 2. 交易前检查清单（逐条打勾，缺一不下单）

```text
[ ] 1. 方向：我判断谁赢？对手侧有没有情报？（双侧对照）
[ ] 2. 价格：当前价格在哪个区间？（>60c 默认小仓或不追）
[ ] 3. 仓位：单笔 ≤30%（30u 账户 = ≤9-10u）？不是全仓？
[ ] 4. 依据：主观判断属于哪一级？（L1/L2/L3，对应探测/标准/加仓）
[ ] 5. 止损：进场同时挂"成本一半"止损单？（决定在事前）
[ ] 6. 止盈：预设止盈梯？（80c 卖一部分 / 90c+ 再卖一部分）
[ ] 7. 连续亏损：今天已连亏几笔？（≥2 笔 -> 强制降档）
[ ] 8. 情绪：我现在是冷静的，还是在回本/报复/连胜膨胀中？
     （情绪激动 -> 30 分钟冷静期，不开新仓）
```

## 3. 进场规则

```text
1. 价格优势线：期望值来自"买入价 vs 结算价"的距离——
   60c 以下方向对至少 1.67 倍，40c=2.5 倍，20c=5 倍，5c=20 倍；
   高于 60c 的新仓默认小仓或不追。
2. 加仓只允许一次，且满足其一：
   a) 价格回落 + 信号确认（如深水反穿上 0.3/0.5）；
   b) L3 双确认（高信心 + 价格进入 S1/S2 区间）。
   禁止：涨起来追高加仓（70c+ 加满 = TSW/DRX C 同族错误）。
3. 总投入（含加仓）不超单场预算；不因"已经涨了"追加。
4. 赛前、赛中、赛后都可入场，但每一笔都过第 2 节检查清单。
```

## 4. 持仓与调仓规则

```text
1. 止损：旧仓跌破"成本一半" -> 无条件退出，不做"暂时落后还是彻底落后"
   的盘中判断；先止损，符合新模板再用新预算重新进场（成本不继承）。
2. 锁盈：价格 ≥80c -> 至少卖出一部分（D2 锁盈）；
   90c+ -> 再卖一部分；剩余小仓可搏 100，但总额已知上限。
3. 调仓三问（每次想调仓前回答）：
   a) 这是规则触发，还是我在怕/在贪？
   b) 新仓位仍 ≤30% 吗？
   c) 调仓理由是新信息，还是情绪？
   只有"规则触发 + 仓位合规 + 新信息"三者同时满足才允许调仓。
4. 深水区（≤20c）小仓买入后不恐慌卖：只认成本一半或启动确认。
5. 小局仓不继承到整场；整场仓不按小局处理（分层记账）。
```

## 5. 退出与熔断

```text
1. 连续 2 笔亏损 -> 下一笔强制降档（探测仓 ≤10u）；
2. 连续 3 笔亏损或当日亏损达账户 30% -> 停止当日交易，只复盘；
3. 账户 30u 亏完 -> 不补仓；钱包 60u 永不入场；先复盘 ≥1 天；
4. 接近终局 / spread 过大 / 数据不更新 -> 自动暂停；
5. 主动平仓必须用户明确表达（按计划自动止盈/止损除外）。
```

## 6. 主观判断的保护（针对"盈利和亏损同源"）

```text
1. 方向判断保留主观（这是优势），但每一笔都要能回答：
   "如果错了，我亏多少？"——答案必须是可承受的（≤30% 账户）。
2. 双侧对照：熟悉队 + 对手侧情报，缺一侧 = 信息不足 = 只允许探测仓。
3. 假赛猜想/剧本猜想需三件套佐证（解说/弹幕提示 + 怪出装/打法异常 +
   盘口异动），只有"感觉" = 赌剧本，按彩票预算处理。
4. 主观判断的置信度不因连胜膨胀：连续 3 笔盈利后，下一笔强制回到
   最小仓（连胜奖励 = 加仓冲动预警）。
5. 复盘闭环：每笔结束写复盘（方向判断对不对 + 仓位对不对分开评），
   判断错了但仓位守住了 = 可接受；判断对了但仓位崩了 = 必须修。
```

## 7. 与现有策略的关系

```text
S0-主观交易是"入口层"：用户的方向判断先进来，
再按价格落位到 S1（低价反转）/ S2（热门回撤）/ P5（整场反转）执行。
执行仍走固定金额制 + M 模块（止盈 / D2 锁盈 / 彩票仓 / 关单 / 复盘）。
```

## 8. 候选评估环节（2026-08-18 补充，扫描结果接入）

```text
扫描器（task2_pipeline / market_scanner）输出候选后，
进入主观规则清单前先过四关：

1. 价格关：当前价是否在策略区间？
   S1 深反 <=15c / S1 中位 20-50c / S2 热门回撤 40-75c；
   >60c 的新仓默认小仓或不追（价格优势线）。
2. 流动性关：24h volume 是否 >= 2 万刀、spread 是否可接受？
   青训/资格赛等低流动性场：单笔降档（探测仓 5-10u），
   或仅观察不主动（spread 偏大时禁止市价追单）。
3. 情报关：我方/对手侧有没有情报？（DNS 新打野、KT 射手弱点等）
   无情报 = 信息不足 = 只允许探测仓。
4. 双确认关：主观方向 + 价格结构是否同时满足？
   只有主观（无价格落位）或只有价格（无主观方向）-> 不进场，
   记入观察列表等触发。

候选处理：
  - 满足四关 -> 进入第 2 节交易前检查清单 -> 逐条打勾后按 S0 执行；
  - 不满足 -> 挂观察（runtime/candidate_action_queue 由 bar monitor 盯），
    等价格触发或情报更新，不提前下单。
```
