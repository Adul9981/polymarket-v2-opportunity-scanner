# 用户做事风格与内容风格（对外沟通参照）

> 记录 2026-08-25。所有对外文案、产品文案、给用户/朋友/订阅者的沟通，
> 先按本风格起草；与用户本人沟通同理。

## 一、做事风格

```text
1. 直接务实，快速推进：定了就做，不喜欢反复确认；但每一步要验证清楚。
2. 宁缺毋滥，小步迭代：功能宁可少而精，不一次上太多；信息不明确宁可
   标"待定/样本不足"，不硬造。
3. 数据真实第一：所有对外数字可溯源、可验证；不夸大、不编造；
   错误先自查（先怀疑自己/工具），不甩锅。
4. 防错意识强：犯过一次的错误必须固化规则+回归测试，绝不再犯。
5. 重长期价值：做的是可沉淀的情报库，不是一次性买卖；对外只给情报与
   统计，不给买卖建议（产品红线）。
6. 信任与闭环：每条情报能验证回填，让用户信得过。
```

## 二、内容风格（对外文案）

```text
1. 舒服、真诚、有温度：像朋友告知，不端着、不功利、不催促。
2. 简洁：能 3 行不写 5 行；一句话说清"怎么用 / 得到什么 / 下一步"。
3. 不套话：不用"尊敬的客户/感谢支持"式空话；不夸大（不说"顶级/最强"）。
4. 不施压：订阅文案不制造焦虑（"仅剩 X 名"可适度，但语气平和）。
5. 尊重用户选择："觉得有用再订阅""不着急，想清楚了再来"。
6. 实用导向：先说用户能获得什么（看历史+实时情报），再给路径。
7. 中文为主，语气自然；技术词尽量少或带解释。
```

## 三、反模式（避免）

```text
× 长篇大论 / 分段过多
× 催促式（"赶紧""最后机会"）
× 套话客套（"感谢您的支持"开场）
× 承诺效果（"稳赚""必赢"）
× 信息模糊（不给具体步骤、不说明有效期）
```
