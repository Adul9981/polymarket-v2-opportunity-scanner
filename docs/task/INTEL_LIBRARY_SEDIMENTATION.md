# 精细化情报库沉淀计划（2026-08-25）

> 定位（用户确认）：弹幕情报输出本质上是为了构建**更精细化的情报库**——
> 每场比赛产出的情报不是终点，而是向长期情报库沉淀的原料；
> 沉淀后反哺下一场的赛前先验与画像，形成"采集 -> 情报 -> 沉淀 -> 先验"闭环。

## 三、沉淀原则

```text
1. 宁缺毋滥：样本不足/信号未确认的条目标"待定"入库，不硬造结论；
2. 每条情报至少 1 条可跨场复用的长期沉淀点（锚点/画像/规律/留痕）；
3. 沉淀与展示分离：JSON/MD 是库（机器+人可读），HTML 是展示派生；
4. 两端一致：服务器沉淀 -> 本地/站点同步（写权限单端优先，防双写冲突）。
```
