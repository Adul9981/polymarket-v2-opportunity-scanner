# 问答助手与使用指南（任务 6）

更新时间：2026-11-24

## 定位

网站新增两个面向用户的入口：

1. 独立“问答 / 使用指南”页面 `intel_help.html`；
2. 全站可收起的问答助手浮窗。

助手复用马斯克工具已经验证过的模式：固定知识库、关键词匹配、快捷问题、
富文本回答、Telegram 双入口和移动端优先。它不连接开放生成模型，避免助手
自身产生新幻觉，也不保存用户原始问题。

## 覆盖主题

RAG/知识库固定覆盖：

- 比赛基本情况：项目、联赛、时间、赛制、状态、队伍、排名、近期表现、H2H；
- 赛前情报：选手、名单、伤停、近期首发、地图池、英雄池、市场共识；
- 核心幻觉识别：来源、时间、身份、因果、概率五类失真；
- 证据分层：事实、市场、共识、推测必须分开；
- 常见问题：状态更新、阵容口径、市场百分比、数据缺口、下载和风险；
- 个人介绍：coveym 的研究方向与公开入口；
- 导流：Telegram 个人号 `@serene7mc`、频道 `@polymarket_ad`；
- 站内引导：今日比赛、赛前情报、历史情报库。

## 公开口径

- 对外统一表述为“AI 综合赛前情报 / 结构化数据 / 可追溯证据”；
- 不在公开页展示底层平台名称；
- 市场百分比只表示赛前市场共识，不表示真实胜率；
- “赛事名单 / 近期首发”不等同“本场官方首发”；
- 缺失数据明确标缺口，不补造字段；
- 不承诺盈利，不构成投资或投注建议。

## 交互与兼容

- 桌面：右侧悬浮窗，宽约 410px，不遮挡主导航；
- 手机：底部响应式面板，使用 `100dvh` 与 safe-area inset；
- 快捷问题支持横向滚动；
- `Enter` 发送，`Escape` 关闭；
- 支持 `?assistant=1` 或 `#assistant` 直接打开；
- `embed=1` 嵌入模式不加载助手，避免与情报壳重复。

## 实现

- `tools/build_intel_help.py`：生成帮助页、助手 CSS 和 JS；
- `tools/add_assistant.py`：向站点 HTML 幂等注入助手资源；
- `reports/intel_help.html`；
- `reports/assistant.css`；
- `reports/assistant.js`；
- `tools/add_site_nav.py`：主导航新增“问答 FAQ”；
- `tools/vps_publish.py`：发布帮助页与助手资源并在全站注入；
- `tests/test_intel_help.py`、`tests/test_add_site_nav.py`。

## 后续扩展

- 新增主题时只扩展固定知识库，不让前端自由生成；
- 收集到的未命中问题只做聚合后人工整理，不保存原始问题文本；
- 如需接入大模型，必须增加来源引用、事实层校验和缺口拒答门禁。
