# 自动化捕捉"深水区反超"（S1-深反彩票 · 候选方案）

> 目标：让自动化在 BO3 比赛中捕捉"落后方深跌后反超"的机会（参考样本：
> CS2 K27 整场 6c→100c、Map2 11c→100c；BRO 1.5c→99.95c；WE/AL 0.65c→100c）。
> 本方案只做"信号检测 + 候选输出"，实盘下单必须过风控红线与人工/autopilot 开关。

## 1. 现象定义（P 层：检测什么）

```text
比赛：BO3（LOL/CS2/DOTA 通用），且处于 Map/Game 2 中段（比赛开始 8~25 分钟）。
对象：Map1 输家（落后方）。
深水区条件（任一）：
  - 落后方单局价格 <= 15c（Map2/Game2）
  - 落后方整场（Moneyline）价格 <= 8c
反转启动确认（必须满足，避免无脑接刀）：
  - 单局价格在深水区后 5~10 分钟内上穿 0.30，进一步上穿 0.50 则升级信号。
```

## 2. 决策规则（S1-深反彩票）

```text
入口 A（深水区低买，彩票预算）：
  - 整场 <=8c 时小仓买入（按归零预算，单市场 <=30 USDC）。
  - 单局 <=15c 时小仓买入（同上）。
入口 B（启动确认，胜率优先）：
  - 单局上穿 0.30 后买入，成本 <=25c；上穿 0.50 时止盈 80%，剩余搏系列赛。
退出：
  - 止盈 80% 于 0.50~0.60（回本优先）；剩余仓位到 0.90+ 或系列赛结束。
  - 若 15 分钟内未上穿 0.30，视为未启动：低买仓按归零预算持有到局末或小止损。
```

## 3. 三层框架落位（TASK2_AUTOMATION_CANDIDATE_FLOW）

```text
L1 触发：1 分钟价格流（bar_monitor_runner / market_scanner）监测进行中 BO3；
  命中"深水区条件"即进入候选。
L2 决策：classify_pattern 判定单局是否上穿 0.30/0.50（反转启动）；
  输出 {event, side, trigger_price, pattern: S1_DEEP_REVERSAL, entry_plan}。
L3 输出：写入 runtime 候选队列（机会候选 JSON），由执行器 dry-run；
  autopilot 关闭时只提示人工确认；开启后仅允许 S1/S2 自主执行。
```

## 4. 风控红线（AGENTS.md）

```text
- autopilot 默认关闭，需要用户在本会话显式开启。
- 限额：每日 $75、单市场 $30、并发 3 个市场；超出即停。
- S1-深反为彩票类：买入即视为彩票仓，止损 = 归零预算，不追加。
- 实盘前先 dry-run；方向/token 解析有歧义时不猜、不下单。
- 主动平仓需用户明确表达；按计划自动止盈/卖出除外。
```

## 5. 验证路径（先回测再小额实盘）

```text
1. 用已入库深反样本（K27、BRO、WE/AL、NIP/IG 等）回测：
   "深水区 <=Xc 后 5-10 分钟上穿 0.30" 的命中率与平均收益（1 分钟粒度）。
2. 统计"整场深水区低买"与"启动确认后买入"两档的期望值，定仓位倍数。
3. 通过后按成熟度升级：L0 观察 -> L1 建议 -> L2 模拟 -> L3 小额实盘（S1-深反彩票）。
```
