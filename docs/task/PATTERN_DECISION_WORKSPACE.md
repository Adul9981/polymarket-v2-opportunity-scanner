## 3. 预测口径

### 3.1 训练样本

读取 `reports/pattern_shapes_*.json` 的 LoL / CS2 / Dota2 形态报告，并补充 `docs/data/snapshots` 中已结算的整场与逐小局价格轨迹；当前训练底座为 3,164 场 / 39,942 个观察点。每个历史轨迹拆成多个观察点，记录：

- 观察点之前可见的价格特征：现价、起点、区间高低、回撤、反弹、斜率、穿越次数、进度；
- 观察点之后才发生的结局：最终形态标签、是否获胜、未来低点与高点；
- 标签来源分层：可见前缀标签用于结构匹配，赛后标签只作为结果监督，不把未来走势伪装成当前形态；
- 同一场比赛、同一市场层级、同一游戏才可进入近邻池。

赛前及赛后平台期不进入形态学习；“回放观察点”只展示截至观察点可见的数据。

### 3.2 相似度

主判断是**当前结构匹配**，不是队伍历史频率匹配。对当前观察点计算特征，先按同游戏、同市场层级、同分钟粒度筛选；BO 赛制样本足够时继续按 BO1/BO3/BO5 隔离，小局样本足够时再按 G1/G2/G3+ 隔离。随后把当前路径与形态模型库逐类比较特征距离，按结构距离优先、相似权重次之排序；候选上限动态跟随形态总库，当前为 16 类：

- `结构相似度`：距离转换后的 0–100% 匹配指数，越接近表示当前路径与该模型结构越相似；不是概率；
- `匹配结构权重`：该形态在全部候选中的距离加权占比，不是胜率；
- `同形后续同向率`：匹配形态的历史相似路径中，后续朝该方向发展的比例；
- `去重同形案例数`：低于门槛时显示“同形证据不足”，不输出完整买卖区间。

两支队伍此前是否多次出现某形态、交手次数或队伍标签均不参与主排序；历史同形案例只负责校准后续方向、路径带和价格分位。

### 3.3 决策卡

每张候选卡给出：

1. 当前路径的结构快照；
2. 匹配到的形态与结构相似度；
3. 方向判断；
4. 建议关注区间；
5. 两档止盈参考与条件失效位；
6. 对应的形态解释与反转证据。

所有数字均来自历史相似样本的分位统计，仅作为交易纪律参考，不构成投资建议。

### 3.4 校准与防止重复计权

- 同一场比赛的多个观察点先归并成一张比赛票，历史方向率按去重比赛数计算。
- 方向率使用 Beta(2,2) 平滑；少于 8 个去重同形案例时只显示“同形证据不足”。
- 买入区围绕现价与未来低点分位收紧，最多约 10c；卡片区分“现价附近 / 回踩区 / 等待回踩”。
- 止盈同时显示历史触达率，避免把单一 97c/100c 终点当作确定性目标。

## 4. 产品边界

- 不把“相似度”写成“准确率”。
- 不在开赛前没有价格轨迹时伪造买卖点；只显示赛前先验或等待有效观察点。
- 不跨 LoL / CS2 借用样本，不把逐局与整场混算。
- 不把 10 分钟级数据冒充 1 分钟级；页面始终展示路径粒度。
- 不自动下单，不主动平仓。
