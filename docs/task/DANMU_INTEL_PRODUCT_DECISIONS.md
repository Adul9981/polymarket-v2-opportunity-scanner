# 弹幕情报库产品决策记录（grill 收尾 · 2026-08-23）

> 本文件是"拷问模式"的共享理解产物：所有已拍板的产品决策，后续执行以本文件为准。

## 1. 定位与范围

```text
产品 = 直播平台弹幕的情报输出（对外订阅收费）。
只做当下比赛的实时情报价值输出 + 赛后沉淀为知识库/情报库（长期资产）。
语言范围：中文（虎牙）为主，韩文（SOOP LCK CL）保留；英文第一期不做。
不做：VOD 历史弹幕回捞（价值低）；朋友历史赔率数据（非必需，可能不是我们要的）。
```

## 2. 定价与付费

```text
主价：$59 / 月（理想价可更高；信息有价值，值得卖更多）。
阶梯：每满 20 个新订阅用户升一档（10%-20%），老用户锁下单价；涨幅累计封顶 +100%。
周期：月度 / 季度（约 9 折）/ 年度（约 8 折）。
定价验证：10 个早鸟名额 $39/月、年度锁定，2 周内看转化（抢完=价格成立，0 转化=降价）。
收款：先 Telegram 人工登记 + 收款（USDT/转账）；量到 20-30 人再上 Polar/Gumroad 自动支付。
```

## 3. 免费 / 付费边界

```text
免费层 = 赛后完整复盘（比赛结束即时开放）——漏斗，引流到线上。
付费层 = 实时情报 + 节点情报 + 赛后完整数据 + 跨场画像 + 时间轴回放。
一句话：免费看"结果与复盘"，付费看"过程与情报"。
```

## 4. 情报输出（时间轴 + 时间点情报页）

```text
8 节点双层时间轴（系列层 × 局层）：
  系列层：赛前（PRE）-> 系列结束（FINAL）
  每局（G1/G2/G3 均适用）：局前 -> BP 锁定 -> 前 10 分钟 -> 20 分钟 -> 30 分钟 -> 局结束
触发：BP/局末按事件检测；10/20/30 分钟按比赛时钟；不做每分钟快照。
每个时间点输出一份"时间点情报页"（不是摘要卡）：
  赛前 / BP / 局中 / 局末复盘 / 系列复盘——结构对齐
  knowledge/LIVE_INTEL_SCHEMA.md（局中 S0-S4 递进，B 型快照）+
  knowledge/REVIEW_SCHEMA.md（10 段完整复盘，A 型）+ INTEL_HTML_TEMPLATE（A/B/C 三类）。
每条情报强制带证据引用（脱敏弹幕原文或时间点），结果类带状态（已验证 / 待验证 / 存疑）。
（"节点情报卡"术语作废，2026-08-23；以"时间点情报页"为准。）
```

## 5. 信任机制

```text
靠"可验证情报的验证痕迹"建立信任，不靠整体命中率营销：
  BP 锚点应验（Kingen 杰斯判死刑）、选手核心位（上单有声音->赢系列）、
  灰信号方向兑现（Monki 2/3）、世界第一奇亚娜带飞等，单条可溯源可查证。
灰信号只做聚合 + 标注"观众质疑，非结论"；弹幕引用脱敏。
```

## 6. 技术架构（分层）

```text
规则管线（底料，脚本）：采集 / 切片 / 词表 / 密度 / 灰信号计数 / 时间戳——确定性提取，自动常驻。
Agent 提炼（情报卡，LLM）：BP 锚点 / 选手核心位 / 信息差叙事 / 验证——判断性提炼，带证据与状态。
LLM API：DeepSeek 起步，接口化可替换；成本约 $0.1/场（全节点）。
VPS：采集常驻 + 规则管线 + 站点 + 付费墙；必须上线，不能依赖本机常开。
访问码付费墙：订阅者持码解锁实时/节点情报；支持到期时间管理。
```

## 7. 排期（压缩版）

```text
M1 VPS 采集常驻 + 规则底料：朋友负责部署（1-2 天）。
M2 访问码付费墙 + QQ/TG 登记：我方实现（1-2 天）。
M3 节点存档 + 时间轴回放：已有大量比赛情报数据，回填归位 + 补存档机制（1-2 天）。
M4 Agent 提炼线上化：与 M1 并行开发（1-2 周），上线期先用本地 Agent 批处理兜底。
核心目标：一周内"能采集、能出节点情报、能收费"。
```

## 8. 推广与种子用户
