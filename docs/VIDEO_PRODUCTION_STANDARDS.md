# 视频制作标准（最高准则）

最后更新：2026-08-15 · 适用范围：本项目全部视频制作材料（录屏讲解、复盘视频、
情报库视频、回测讲解等）

## 原则 0（最高准则，不可违反）

```text
1. 图文并茂：视频页面/材料必须以可视化为主，禁止大段文字堆砌；
   每个观点必须有图（图表/示意图/对比图），文字只做短标注与结论。
2. 必含三类分析形式：
   - 图片/示意图（价格图、时间线、流程图、示意卡）
   - 占比分析（环形图、条形占比、HP 血条式比例）
   - 对比分析（嫌疑场 vs 对照组、赢家 vs 割肉者、机器 vs 真人等成对呈现）
3. 融入《英雄联盟》元素：使用英雄联盟视觉语言（蓝方/红方、金币金、符文蓝、
   血条、KDA 式数据块、召唤师图标、迷你地图/小龙/大龙点位），
   但必须克制、不喧宾夺主，底色仍以 SAP/Apple 浅色风格为准。
4. 趣味性优先：数字做成人话（"25 分钟从 94 分崩到 0.1 分"），
   角色做成人设（"深水机器""割肉哥"），转折做成分镜。
5. 文字减量：单屏正文不超过 2-3 行；数字和结论放大显示，解释放旁白。
```

## 1. 视觉规范

```text
- 基底：SAP/Apple 浅色 #f5f5f7、白色圆角卡片、系统字体栈（-apple-system/PingFang SC）。
- 强调色（三色克制）：LoL 金 #C8AA6E、蓝方 #0397AB（或 #009D9D）、红方 #C6443E；
  正文 #1D1D1F，次要 #6E6E73。禁止霓虹色与大面积深色渐变（封面深蓝 #0A1428 除外）。
- 字号：录屏基准 1280 宽；标题 >= 40px、正文 >= 20px、数据数字 >= 48px。
- 一屏一观点：每 section 一个核心结论，不堆叠。
- 来源角标：每张图/数据卡底部固定标注"数据：Polymarket 公开接口 · 行为推断"。
```

## 2. 内容准则

```text
1. 证据分级必须展示：链上解码（硬）/ 接口数据（中）/ 行为推断（软）；
   推断结论一律用"疑似/嫌疑/行为上"表述，不点名指控具体个人。
2. 地址脱敏：页面上只显示前 6 后 4（0x1234…abcd），完整地址放报告与台账。
3. "假赛"等指控性前提必须标注"未独立验证，为观赛推断"。
4. 每个对比必须可控：对照组用同日/同赛事/同赛制，避免选择性对比。
5. 时间统一标注时区（UTC/北京时间），避免跨时区误解。
6. 数据页脚注明生成日期与数据截止时间。
```

## 3. 节奏与分镜（录视频用）

```text
1. 开场钩子：一句话反转结论（如"94 分崩到 0.1 分，解说一直在喊假赛"）。
2. 第一视角 -> 数据 -> 对照组 -> 规则，四段式推进，每段不超过 90 秒。
3. 关键数字用"血条/环形/对比条"呈现，不读数字，指图讲结论。
4. 结尾固定三件事：结论、数据在哪、下一步验证。
```

## 4. 制作检查清单（录屏前过一遍）

```text
□ 1280+ 分辨率，无缩放模糊
□ 每屏一观点，无大段文字
□ 每张图有来源角标与日期
□ 地址已脱敏（前6后4）
□ "假赛/疑似"措辞合规
□ 无个人真实信息/隐私泄露
□ 动画克制（淡入/位移，不用闪烁）
□ 移动端也能顺读（响应式）
```
