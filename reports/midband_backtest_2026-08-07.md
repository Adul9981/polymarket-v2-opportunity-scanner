# 中位组合回测：买80回收 + 跌破成本一半止损（2026-08-07）

数据：08-05/08-06 实盘交易的 21 个市场（Polymarket CLOB 1 分钟粒度，含 LOL/CS2/Dota2/网球/WNBA/Elon，
排除深反类 WE 与无法解析的 T1/DK）。价格历史抓取见 /tmp/midband_backtest5/。

规则：

```text
入场：价格首次触及 25/30/35/40/45/50c 时买入（限价单假设，无滑点）。
止盈：80% 成本在 70c 或 80c 卖出（买80回收）；20% 彩票持有到末段。
止损：跌破成本一半（P/2）即离场，亏损封顶 -50%。
```

## 关键结论

1. 保底收益率（止盈达成时）符合设计公式：30c 入场 70c 卖出 = +87%，80c 卖出 = +113%；
   40c 入场 = +40%/+60%；50c 入场 = +12%/+28%。入场越低保底越高。
2. 止损触发率极高（68-93%）——但本样本以 08-05 亏损日为主（21 场中 12 场是当天接刀/追高
   后归零的仓位）。这说明：**不加方向过滤的"见跌就买"中位网格是负期望**，止损只是把
   -100% 压到 -50%，救不了错误的方向选择。
3. 反例对照（系统性规则 vs 实际手动）：
   - cs2 Liquid G1：30c 系统性入场 -> 70c 卖 80% -> +153%；实际手动 69c 买入/管理失误 -> -12。
   - dota2 YB1 G1：30c 系统性入场 -> 70c 卖 80% -> +87%；实际手动 69c 低吸 + 98c 追高 -> -54。
   同样的市场，规则化低吸 + 买80回收能赢，手动高位追/漏止盈就输。
4. 08-06 的盈利单（NRG、T1A、BESTIA、GIANTX）入场价普遍在 55-75c（S2/P-早建仓区间），
   25-50c 网格没有触发——中位入场规则天然错过这些，它们属于"热门回撤/早买"通道。

## 局限

```text
- 样本只有 2 天 21 场，统计意义有限；这是可行性检查，不是结论。
- 未建模方向过滤（真实策略只在"看好某一侧"时入场）；无滑点/成交率假设；
  限价单按触及即成交处理。
- T1/DK 未能解析事件 slug，WE 属深反类已排除。
```

## 修正版：方向过滤 + 电竞市场 + 穿越入场（2026-08-07 追加）

前一轮全 100% 止损率为数据假象，原因：

```text
1. 08-05/08-06 这些市场生命周期 4 天，公开接口只返回 5-13 分钟粗粒度（不是 1 分钟）。
2. 比赛窗口裁剪把赛后的 0.0005/0.9995 平台段算进去，且入场按"触及即成交"导致平台段假入场。
修正：不裁剪窗口；入场要求价格从上往下穿越入场价（前一点 > P，当前点 <= P）才成交；
只统计电竞市场（LOL/CS2/Dota2，17 个），方向 = 用户实际下注侧。
```

解读：

```text

  或依赖打点程序/朋友数据源）——这正是环节 5 数据粒度评估项。
```
