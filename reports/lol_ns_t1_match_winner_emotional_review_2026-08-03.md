这不是一次独立错误，而是一个反复出现的模式：

```text
前面判断对了

但因为想拿最终结算
不愿意卖掉剩余仓位

```

此刻感受：

慌乱

## 关键错误

### 错误 1：赛前低胜率方向买入金额过大

T1 约 28c 时买入 $130-$150，本质上已经不是小彩票，而是重仓方向判断。

这会导致：

```text
后续每个决策都被仓位大小影响
一旦浮盈很大，更不愿意只拿一部分
一旦亏损，也容易被沉没成本影响
```

### 错误 2：卖出了一部分，但没有给剩余仓位自动止盈

65c 卖出约 $90 是正确动作。

问题在于：

```text
剩余 300 shares 没有继续分档卖
没有 75c / 80c / 回撤线的自动保护
最后变成全靠人工临场判断
```

### 错误 3：把“已到手的高浮盈”继续当作“应该拿到的终局收益”

当剩余仓位值到 $160-$240 时，已经是非常好的交易结果。

但心理目标变成：

```text
为什么不拿满 $300？
只差一点了。
```

这会把已经完成的好交易，重新变成一次高风险赌博。

### 错误 4：没有尊重尾盘跳变风险

公开数据显示，T1 从最高 79.5c 到 0.5c 大约 6 分钟。

这类市场尾盘不是线性回撤，而是跳变：

```text
一波团战
一次失误
一次基地推进
价格直接从高位打到接近 0
```

人工通常来不及反应。

## 如果机器接管，应该怎么做

### 规则 1：赛前低价仓必须拆成“本金回收 + 浮盈保护 + 彩票仓”

示例：

```text
28c 买入
65c 卖出第一档，回收本金和部分利润
75c 卖出第二档，锁定大部分浮盈
80c 附近卖出第三档，只留小彩票仓
```

### 规则 2：剩余彩票仓不能太大

这次剩余约 300 shares，对心理来说已经不是小彩票仓。

第一版建议：

```text
彩票仓最大只保留原始成本的 10%-20%
或只保留已实现利润的一小部分
```

当彩票仓市值超过某个阈值时，必须继续卖：

```text
剩余仓市值 > 初始投入的 1x：卖一部分
剩余仓市值 > 初始投入的 1.5x：再卖一部分
剩余仓市值 > 初始投入的 2x：只留最小彩票
```

### 规则 3：高位回撤自动保护

如果价格已经到 75c-80c，不能再让它无保护地回到 50c 以下。

第一版建议：

```text
到 75c 后，设置回撤保护线 65c
到 80c 后，设置回撤保护线 70c
如果跌破保护线，自动卖出大部分剩余仓位
```

### 规则 4：尾盘不能贪全额结算

越接近终局，价格越跳变，人工越容易被“再等一下”控制。

系统规则：

```text
如果剩余仓位已经有明显浮盈
且比赛进入尾盘/终局阶段
必须自动减仓
不能把大部分仓位留到最后一波团战
```

## 候选策略 D：浮盈保护 / 自动锁盈

这次复盘提出一个新的候选策略：

```text
策略 D：浮盈保护 / 自动锁盈
```

它不是找买点，而是管已经赚钱的仓位。

适用场景：

```text
赛前或低位买入后
价格已经上涨到 60c-80c
仓位浮盈明显
用户主观上想继续拿到结算
```

系统目标：

```text
不让一笔已经成功的交易，重新变成归零风险。
```

第一版动作：

```text
60-65c：回收本金
70-75c：锁定主要利润
80c+：只留小彩票仓
高位后跌破保护线：自动卖出
```

## 一句话总结

这次不是“不会判断”，恰恰相反，是前面判断很强。

真正的问题是：

```text
方向判断成功之后，没有让机器接管卖出纪律。
```

下一版系统要解决的不是让人更冷静，而是：

```text
让人负责发现机会。
让机器负责不让贪心毁掉已经到手的收益。
```
