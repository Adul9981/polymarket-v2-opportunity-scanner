验证方向：

核心结论：
这是目前最重要的组合型样本。它同时验证了策略 A，并提出了一个新的“赛前低价仓位止盈 + 中局深跌再入场”的组合流程。

## 走势分解

```text
早期低位：T1 触及 39c / 34.5c 附近
前期优势：T1 最高升至 83.5c
中期崩盘：T1 最低跌至 4.5c
终局反转：T1 最后回到 100c
50% 穿越：6 次
```

这个走势本质上有三段机会：

```text
第一段：赛前或早期低价买入
第二段：前期优势到 80c+ 时主动止盈
第三段：中期深跌到 20c / 10c 以下后，重新按策略 A 入场
```

## 已被样本验证的策略

### 已验证 1：策略 A 标准深度反转

样本：

```text
DNF-BRO Game 2
Dota2 GLYPH-PlayTime Game 2
NS-T1 Game 1
```

规则：

```text
20-30c 区间开始买
继续向下分层买
40/50/60c 自动挂卖
保留固定成本彩票仓
```

验证点：
不需要最终一定到 100c。只要低位买入后能回到 40/50/60c，主要收益就能成立；如果最终回到 100c，彩票仓提供额外放大。

### 已验证 2：策略 A 彩票子类

样本：

```text
DNF-BRO Game 2：最低 13.5c
NS-T1 Game 1：最低 4.5c
```

规则：

```text
10c 以下只做小额彩票
不无限加仓
目标是 3x / 5x / 最终命中
```

验证点：
极端低价不是普通网格，而是高亏损概率、高赔率回报的独立子类。它应该使用更小固定金额。

### 已验证 3：策略 B 强队临时低估

样本：

```text
LNG-IG Game 1
```

规则：

```text
强队从高位回落到 60-80c
小网格买入
反弹后分档卖出
若继续跌破 40c，则 B 型降级，不再追加
```

验证点：
B 型的关键不是“全程不破 40c”，而是入场窗口是否有效。跌破 40c 后应该停止 B 型加仓，只管理已有仓位。

## 新发现但需要继续验证的策略

### 待验证 1：赛前低价仓位的前期优势止盈

NS-T1 Game 1 提出了一个新规则：

```text
如果赛前或早期在 35-40c 买入
比赛前 15 分钟因优势升到 80c+
应主动卖出大部分仓位
只留小彩票仓
```

意义：
这不是策略 A，也不是策略 B，而是“低价预判仓位的优势兑现”。它能避免 80c 不卖、随后跌回 6c 的巨大回撤。

第一版可执行规则：

```text
35-40c 建仓
75-85c 卖出 70-85% 成本份额
保留 15-30% 彩票仓
如果后续跌回 20-30c，重新开启策略 A
```

### 待验证 2：同一方向的二次入场

NS-T1 Game 1 的路径是：

```text
低价买入 -> 80c 止盈 -> 跌到 6c -> 再次反转到 100c
```

这说明卖出并不等于放弃该方向。一个方向在兑现后，如果重新进入深度低估区，可以再次按策略 A 入场。

需要继续验证：

```text
卖出后重新入场是否容易过度交易
第二次入场金额是否应该低于第一次
10c 以下是否只允许彩票仓，不允许普通网格
```

### 待验证 3：极端波动中的多轮网格

当前策略 A 允许最多 2 轮，但还需要更多样本验证：

```text
第一轮 20-30c 买，40c 卖一部分
如果再次跌回 20-25c，是否允许第二轮补单
如果价格已经发生终局跳变，是否禁止新开
```

建议第一版限制：

```text
单场最多 2 轮
第二轮金额不超过第一轮
10c 以下只开彩票子类
```

### 待验证 4：策略 C 极端低价反转彩票

这是从 NS-T1、DNF-BRO、Dota2 GLYPH-PlayTime、DK 失败样本里共同提炼出来的新候选策略。

适用区间：

```text
3c-10c
```

核心逻辑：

```text
用极小固定金额买极端低价方向
接受大概率归零
只捕捉少数从几美分反弹到几十美分甚至 100c 的机会
```

第一版规则：

```text
单次 $3-$5
单场最多 $5-$10
同一小局只允许一个方向进入策略 C
不能两边都买
不能亏了以后继续补大
买入后自动挂 2x / 4x / 30-40c / 60c+ 分档卖出
```

为什么不能两边买：

```text
极端波动里两边都可能短暂很便宜
但最终只有一边结算为 100c
双边买会把彩票策略变成持续漏损
```

当前状态：

```text
候选策略
先提醒 + 手动确认
暂不全自动执行
```

### 待验证 5：策略 D 浮盈保护 / 自动锁盈

这是从 NS-T1 Match Winner 这次操作里提炼出来的新候选策略。

它不是找买点，而是管已经赚钱的仓位。

适用场景：

```text
低价或赛前仓位已经明显浮盈
价格已经从 25-35c 涨到 65-80c
用户主观上想拿最终结算
但尾盘跳变风险很高
```

核心问题：

```text
从 79.5c 到 100c，只多赚 20.5c
但从 79.5c 到 0，可能损失整段高位浮盈
```

NS-T1 Match Winner 样本验证：

```text
第三局阶段低位：25.5c-30.5c
最高：79.5c
约 6 分钟后：0.5c
```

第一版规则：

```text
65c：回收本金和部分利润
75c：锁定大部分浮盈
80c：只保留小彩票仓
高位后跌破 65c/70c：自动保护卖出
```

当前状态：

```text
候选策略
优先进入自动执行层
因为它处理的是卖出纪律，而不是新增风险敞口
```

## 对自动化交易产品的更新

新增一个“持仓状态识别”：

```text
无仓：只判断 A/B 入场机会
已有赛前仓：优先判断是否需要在 75-85c 回收
已止盈小仓：继续观察是否重新进入 A 型
深跌彩票仓：不加仓，只等待反弹或结算
```

这会让产品从“只找买点”升级成：

```text
买点识别
卖点前置
止盈后再入场判断
彩票仓管理
```
