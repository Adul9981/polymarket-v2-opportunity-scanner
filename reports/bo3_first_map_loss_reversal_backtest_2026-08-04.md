# BO3 首局落后 / 前半段落后反转样本回测

日期：2026-08-04

## 结论摘要

这三场样本共同验证了一个高频形态：

```text
BO3 比赛中，某一方第一小局输了，或前半段明显落后；
整场 Match Winner 赔率会被压低；
如果该队伍仍具备系列赛翻盘能力，后续修复空间很大；
系统可以围绕 Match Winner，而不是单局 Winner，自动识别并执行。
```

它不完全等同于原来的策略 A 或策略 B，更适合作为一个新的子策略：

```text
E：BO3 首局失利 / 前半段落后后的系列赛反转
```

E 不是独立于 A/B 的全新交易逻辑，而是一个自动发现标签：

```text
低价 10c-30c：走策略 A 深度反转。
中价 30c-45c：走 A2 中位反转，需要更保守预算。
高价 55c-70c：走 B2 强队折价修复。
盈利后统一接入 D2 自动锁盈。
```

## 自动化策略建议：新增 E 型发现标签

E 型用于发现，不直接替代 A/B。

第一版 E 型识别条件：

```text
市场必须是 Match Winner / Series Winner。
比赛赛制必须是 BO3 或 BO5。
当前不是最后一局接近终局。
目标方第一小局输掉，或第一小局/前半段明显落后。
目标方整场价格出现折价。
市场仍有足够成交量和盘口深度。
```

如果暂时没有实时赛况数据，第一版可以只用价格序列近似判断：

```text
开局或赛前价格 >= 55c，随后跌到 55c-70c：标记 E-B2。
开局或赛前价格 >= 55c，随后跌到 30c-45c：标记 E-A2。
开局或赛前价格 <= 35c，随后跌到 10c-30c：标记 E-A。
价格低点后 15-30 分钟仍未接近终局，才允许执行。
```

## 执行模板建议

### E-A：低价系列赛反转

适用：

```text
目标方 10c-30c。
通常是弱队或首局失利后被市场极度低估。
```

执行：

```text
复用策略 A。
单轮 $25。
20c-30c 分层买。
40c / 50c / 60c 分层卖。
保留小彩票仓。
```

### E-A2：中位系列赛反转

适用：

```text
目标方 30c-45c。
首局失利或中段落后，但仍有明显翻盘空间。
```

建议第一版：

```text
单轮 $15-$20，不超过标准 A。
40c 附近买第一档。
35c 附近买第二档。
30c 附近买第三档。
55c / 70c / 85c 分层卖。
保留极小彩票仓。
```

注意：

```text
E-A2 比 A 更容易买贵，必须更重视 D2 自动锁盈。
```

### E-B2：强队折价修复

适用：

```text
目标方赛前或早段是热门方。
因为首局落后或第一小局失利，价格跌到 55c-70c。
```

执行：

```text
复用策略 B。
单轮 $25。
当前价附近买第一档。
低 4c-5c 买第二档。
反弹 +12c / +22c / 98c 分层卖。
```

注意：

```text
如果价格跌破 40c，B2 不再继续加仓，转入 E-A2 或只管理已有仓位。
```

## 和 D2 自动锁盈的关系

这三场共同说明：

```text
买入机会经常会出现；
真正决定收益稳定性的，是反弹后能否自动卖出。
```

因此 E 型必须默认接入 D2：

```text
60c 以上开始回收。
75c 以上锁定大部分。
80c 以上只保留小彩票仓。
触达高位后，如果回撤到保护线，自动卖出主要剩余仓。
```

## 产品实现优先级

第一版自动化不需要马上读完整战局数据，可以先按价格序列做：

```text
1. 扫描 BO3 / BO5 Match Winner 市场。
2. 找出开盘/早段价格与当前价格的折价。
3. 判断目标方是否进入 E-A / E-A2 / E-B2 区间。
4. 检查成交量、spread、价格更新时间。
5. 生成固定金额交易计划。
6. 买入成交后自动挂卖。
7. 接入 D2 自动锁盈。
```

后续如果能接入实时赛况，再增强：

```text
第一小局胜负。
当前小局比分。
是否决胜局。
是否接近终局。
LoL 经济/人头/龙魂/大龙。
CS 地图比分和攻防半场。
Dota 经济差、塔、肉山、买活。
```
